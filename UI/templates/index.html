About the Translator

How to Use the Translator

  1. Enter Text: Type your English text in the left input box or click one of the example phrases below.
  2. Translate: Click the "Translate" button in the middle or press Ctrl+Enter to translate.
  3. View Results: The Twi translation will appear in the right box.
  4. Use the Tools:
    • - Clear the input text
    • - Record speech (if available)
    • - Listen to the translation
    • - Copy the translation to clipboard

About the Project

This English to Twi translator is powered by a PyTorch Transformer neural network. It was trained on a dataset of English-Twi sentence pairs to learn how to translate between these languages.

Limitations

While the translator works well for common phrases and sentences, it may struggle with:

  • Very long or complex sentences
  • Technical terminology
  • Idiomatic expressions

Built using PyTorch, Transformer architecture, and Flask.
